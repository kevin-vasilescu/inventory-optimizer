# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-24

### Added
- Loading and row-numbered validation of sales and inventory CSV files.
- Demand statistics, ABC and XYZ classification, safety stock, reorder point and EOQ.
- Per-SKU status (DEAD, CRITICAL, REORDER, OVERSTOCK, OK) and recommended order quantities.
- Supplier purchase-order drafts in CSV and Markdown.
- Markdown, HTML, JSON, CSV and Excel reports.
- `invopt` command line with `analyze`, `po`, `validate` and `sample`.
