# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting (Security tab, "Report a vulnerability") on this repository. Include a description, reproduction steps and the affected version. You can expect an acknowledgement within a few days.

## Scope

The tool reads local CSV files and writes local reports. It makes no network requests and handles no credentials. Generated HTML reports are self-contained and escape all data values.
